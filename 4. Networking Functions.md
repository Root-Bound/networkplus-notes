CDN #cdn
	Content Delivery Network
	Geographically distributed caching servers, duplicate the data and speed up the process, users get the data from a local server, invisible to the end user

VPN #vpn
	Virtual Private Network
	Allows you to remotely connect to a network over encrypted communication
	Often use a Concentrator or head-end, usually integrated into a firewall, is the encryption/decription device
	Specialized cryptographic hardware, also software-based options available

QoS #QoS
	Quality of Service
	Traffic shaping, packet shaping. Prioritization for different applications
	Control by bandwidth usage or data rates
	QoS lists are usually integrated in Routers, switches and more

TTL #ttl
	Time to live
	How long should data be available? Not all systems are self-regulating, sometimes we need to tell the system to stop
	Is basically a timer, there are many different uses, for example drop a packet caught in a loop, or clear a cache
	Routing loops
	Router A thinks the next hop is to Router B and Router B thinks the next hop is to router A and repeat. This can't go on forever, TTL is used to stop the loop.
	Internet Protocol has this stop implemented already
	Loops could cause a packet to live forever, drop the packet after a certain number of hops
	Default TTL's:
	macOS/Linux: 64hops (TTL=64)
	Windows: 128 hops
	A TTL of zero is dropped by the router

DNS #DNS
	Domain Name System
	The TTL is associated with actual seconds. Resolve an IP address from a fully-qualified domain name. A device caches the lookup for a certain amount of time. How long? TTL seconds long. 

**DNS TTL is measured in SECONDS — routing TTL is measured in HOPS.** Different TTLs, different contexts. Don't confuse them on the exam.
