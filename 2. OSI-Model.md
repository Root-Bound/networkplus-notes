Layer 7 - Application #layer7
	The layer we see on our screen. Anything we see with our eyes are at this level. Common applications are: HTTP, HTTPS, FTP, DNS, POP3 and thousands more
YOUR EYES

Layer 6 - Presentation #layer6
	This layer is responsible for putting all of that Data together so we can actually see it for the first time with our human eyes. This is the layer where characters get encoded, applications are encrypted/decrypted, and is usually combined (talked about ) with Layer 7
APPLICATION ENCRYPTION, SSL / TLS

Layer 5 - Session #layer5
	Provides communication management between point A and point B. If an application is using some type of control protocol or you're tunneling information within existing data, then you're probably using this layer.
CONTROL PROTOCOLS, TUNNELING PROTOCOLS

Layer 4 - Transport #layer4
	Post office layer, Parcels and letters. Usuallly TCP and UDP operate at this Layer. (Transmission Control Protocol and User Datagram Protocol )
	Breaks down large amount of data into packets, sends them across Layer 3 and Pieces them back together on the other end
TCP SEGMENT, UDP DATAGRAM

Layer 3 - Network #layer3
	Also the routing Layer. It's the layer routers use to forward traffic. IP Internet Protocol is present here. Fragments frames to traverse different Networks.
	Anything related to an IP Address is probably on this layer
IP-ADDRESSES, ROUTER, PACKET

Layer 2 - Data Link #layer2
	Fundamental layer on which two devices communicate on the network "basic network language"
	Data Link Control DLC protocols like MAC address on Ethernet are present here
	Often Referred as the MAC Address Layers
	It is also the Switching layer
SWITCH, NIC, EUI

Layer 1 - Physical #layer1
	 Signaling, cabling, connectors. No Protocols. Issues can be Interference in Wireless networks, Troubleshooting: running loopback tests, punchdowns, replace cables
THE SIGNAL ITSELF

Mnemonic to memorize (top to bottom): All People Seem To Need Data Processing
